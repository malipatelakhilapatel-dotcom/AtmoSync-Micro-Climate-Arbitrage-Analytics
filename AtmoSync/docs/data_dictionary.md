# AtmoSync — Data Dictionary

**Author:** Member 3 — Superset & Documentation

## 1. Raw Layer (`RAW`)

### Table: `RAW.SENSOR_TELEMETRY`
Direct landing table for IoT container streaming events.

| Column Name | Data Type | Nullable | Unit / Format | Description |
|---|---|---|---|---|
| `record_id` | VARCHAR(64) | NO | UUID | Unique telemetry reading identifier |
| `ingestion_timestamp` | TIMESTAMP_NTZ | NO | UTC ISO-8601 | Timestamp when Snowflake ingested record |
| `timestamp` | TIMESTAMP_NTZ | NO | UTC ISO-8601 | Measurement timestamp generated by sensor |
| `container_id` | VARCHAR(50) | NO | e.g. `CONT_001` | Unique container asset identifier |
| `shipment_id` | VARCHAR(50) | NO | e.g. `SHIP_001` | Logistics consignment identifier |
| `commodity` | VARCHAR(50) | NO | Enum | Cargo type (`Avocado`, `Banana`, `Tomato`, `Mango`, `Apple`) |
| `temperature_c` | NUMBER(5,2) | NO | Celsius (°C) | Core internal container temperature |
| `humidity_pct` | NUMBER(5,2) | NO | Percentage (%) | Relative humidity |
| `vibration_g` | NUMBER(5,2) | NO | Acceleration ($g$) | Tri-axial mechanical shock |
| `latitude` | NUMBER(9,6) | NO | Degrees Decimal | Current GPS latitude coordinate |
| `longitude` | NUMBER(9,6) | NO | Degrees Decimal | Current GPS longitude coordinate |
| `origin` | VARCHAR(100) | NO | City Name | Dispatch hub / farm terminal |
| `destination` | VARCHAR(100) | NO | City Name | Primary planned wholesale delivery terminal |
| `quantity_kg` | NUMBER(10,0) | NO | Kilograms | Total payload cargo weight |
| `speed_kmh` | NUMBER(5,2) | YES | km/h | Current transit velocity |
| `door_open` | BOOLEAN | YES | Boolean | Tamper / inspection door sensor |
| `compressor_status` | VARCHAR(20) | YES | Enum | Status: `NORMAL`, `DEGRADED`, `FAILURE` |
| `anomaly_mode` | VARCHAR(50) | YES | Enum | Simulator mode tag |

---

### Table: `RAW.COMMODITY_PRICES`
Wholesale spot price reference table.

| Column Name | Data Type | Nullable | Unit | Description |
|---|---|---|---|---|
| `market` | VARCHAR(100) | NO | City | Wholesale terminal market |
| `commodity` | VARCHAR(50) | NO | String | Agricultural commodity |
| `price_per_kg` | NUMBER(10,2) | NO | Currency / kg | Real-time wholesale spot price per kg |
| `currency` | VARCHAR(10) | NO | Code | Default `INR` (Indian Rupee) |
| `last_updated` | TIMESTAMP_NTZ | NO | UTC | Timestamp of price update |

---

### Table: `RAW.MARKETS`
Wholesale terminal metadata and logistics capacity.

| Column Name | Data Type | Nullable | Description |
|---|---|---|---|
| `market_id` | VARCHAR(20) | NO (PK) | Unique market code (e.g. `MKT_MUM`) |
| `market_name` | VARCHAR(100) | NO | Market terminal city name |
| `latitude` | NUMBER(9,6) | NO | Terminal GPS latitude |
| `longitude` | NUMBER(9,6) | NO | Terminal GPS longitude |
| `state` | VARCHAR(100) | NO | Administrative state |
| `tier` | VARCHAR(20) | NO | Market classification (`Tier-1`, `Tier-2`) |
| `handling_fee_pct` | NUMBER(4,3) | NO | Offloading & terminal handling fee rate |
| `cold_storage_capacity_tons` | NUMBER(10,0) | NO | Available cold-storage warehousing capacity |

---

### Table: `RAW.ROUTES`
Pre-defined transport corridors and logistics parameters.

| Column Name | Data Type | Nullable | Description |
|---|---|---|---|
| `route_id` | VARCHAR(50) | NO (PK) | Logistics corridor code (e.g. `RT_NSK_MUM`) |
| `origin` | VARCHAR(100) | NO | Origin city |
| `destination` | VARCHAR(100) | NO | Destination city |
| `distance_km` | NUMBER(8,2) | NO | Total corridor distance in kilometers |
| `estimated_transit_hours` | NUMBER(6,2) | NO | Baseline travel duration in hours |
| `toll_cost_inr` | NUMBER(10,2) | YES | Highway toll expense |
| `road_condition_index` | NUMBER(4,2) | YES | Pavement quality factor (0.0 to 1.0) |

## 2. Analytics Mart Layer (`ANALYTICS`)

### Table: `ANALYTICS.FCT_SPOILAGE_ARBITRAGE`
The primary mart consumed by Superset and trading desks.

| Column Name | Data Type | Description |
|---|---|---|
| `container_id` | VARCHAR(50) (PK) | Container identifier |
| `commodity` | VARCHAR(50) | Perishable crop |
| `spoilage_risk_score` | FLOAT | Computed degradation score ($0.0 - 100.0$) |
| `risk_category` | VARCHAR(20) | `Low Risk`, `Moderate Risk`, `High Risk`, `Critical Risk` |
| `time_to_spoilage_hours` | FLOAT | Hours until cargo quality falls below commercial grade |
| `current_destination` | VARCHAR(100) | Planned primary delivery market |
| `current_transit_hours` | FLOAT | Remaining travel hours to planned destination |
| `current_market_price` | FLOAT | Wholesale price at current destination (₹/kg) |
| `current_expected_value_inr` | FLOAT | Net Realizable Value if container continues along primary route |
| `current_potential_loss_inr` | FLOAT | Financial value of decayed cargo if continuing primary route |
| `recommended_destination` | VARCHAR(100) | Optimal alternative market terminal |
| `reroute_distance_km` | FLOAT | Distance from current GPS coordinates to recommended terminal |
| `reroute_transit_hours` | FLOAT | Travel hours to reach recommended terminal |
| `reroute_freight_cost_inr` | FLOAT | Fuel, toll, and refrigeration cost of detour |
| `reroute_expected_value_inr` | FLOAT | Net Realizable Value if rerouted |
| `spoilage_arbitrage_inr` | FLOAT | **Key Metric**: Net financial benefit from rerouting ($\Delta \text{NRV}$) |
| `spoilage_avoided_value_inr` | FLOAT | Gross value of spoilage losses prevented |
| `is_reroute_recommended` | BOOLEAN | **Action Flag**: TRUE if reroute yields positive arbitrage and is reachable |
| `recommendation_reason` | VARCHAR | Transparent business rationale explaining decision |
